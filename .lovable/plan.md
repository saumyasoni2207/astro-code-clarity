# AstroNumero Clarity Website

## Goal
Build a polished, mobile-first consultancy website that turns visitors into free-audit and consultation leads.

## Experience
- Create a sticky branded header with responsive navigation and booking action.
- Build a high-impact opening section with astrology/numerology visual accents and direct paths to the free audit and packages.
- Add an interactive Life Path calculator that supports master numbers 11 and 22, with traits and lucky numbers.
- Build the complete Free Kundli & Destiny Audit form with live validation, India-first phone input, birth date input, aura color swatches, and concern field.
- Show a personalized confirmation modal after valid submission, including the visitor’s details and a safely encoded WhatsApp handoff.
- Add the four-level pricing ladder, client trust signals, verified testimonials, and accessible FAQ accordion.
- Add a two-action mobile bar for the audit and WhatsApp.

## Visual Direction
- Use the requested pitch-black, midnight navy, metallic gold, electric blue, crisp white, and slate palette.
- Pair Playfair Display headings with Plus Jakarta Sans body text.
- Use restrained glass surfaces, luminous borders, 16px card corners, generous touch targets, and subtle motion with reduced-motion support.
- Create an original celestial numerology visual treatment with lightweight CSS and SVG accents rather than stock imagery.

## Technical Details
- Keep the experience on the home route with semantic page structure and smooth in-page navigation.
- Use React state for form validation, color selection, calculator results, accordion state, and the confirmation dialog.
- Use accessible labels, error messaging, focus management, keyboard-friendly controls, and dialog semantics.
- Add route-specific title, description, Open Graph, Twitter, and canonical metadata.
- Verify compilation plus desktop and mobile rendering and interactions in the live preview.
